1. Executive Summary

RANDTEK IT Solution proposes RandJuris — a comprehensive web-based platform designed specifically for law firms operating in the Philippines and similar jurisdictions. The system centralizes client management, case tracking, document storage, task coordination, calendar scheduling, billing in Philippine Peso (₱), and audit logging into a single secure environment.

Key Value Proposition: Replace fragmented spreadsheets, email threads, and paper-based workflows with a unified digital platform that improves productivity, reduces errors, strengthens client service, and provides full visibility into firm operations — all while enforcing role-based security appropriate for legal practice.

Phase 1 of the platform has been developed and is operational, delivering ten core modules with enterprise-grade authentication, seven distinct user roles, and a modern responsive interface. This proposal outlines the system's capabilities, technical foundation, delivery status, and recommended path forward for deployment and ongoing enhancement.

2. Background & Problem Statement

Industry Challenges

Law firms face recurring operational challenges that impact profitability and client satisfaction:

  • Disconnected data — Client records, case files, billing, and schedules stored across multiple tools with no single source of truth.
  • Manual billing inefficiency — Time tracking and invoice generation done manually, leading to revenue leakage and delayed collections.
  • Document management risk — Critical legal documents scattered in email attachments or local drives without version control or access logs.
  • Poor team coordination — Tasks, deadlines, and court appearances not visible to all relevant staff in real time.
  • Compliance gaps — Limited audit trails make it difficult to demonstrate who accessed or modified sensitive records.
  • Scalability limits — As the firm grows, informal processes break down and onboarding new staff becomes costly.

Business Need

The firm requires a purpose-built management system that addresses these pain points while remaining affordable to deploy, intuitive for non-technical staff, and secure enough to handle privileged client information.

3. Proposed Solution

The RandJuris is a full-stack web application that provides a centralized portal for all firm stakeholders — partners, lawyers, paralegals, secretaries, accountants, and optionally clients — to perform their daily work within clearly defined permission boundaries.

Solution Highlights

  • Cloud-ready web application accessible from any modern browser
  • Role-based access control (RBAC) with seven predefined user roles
  • End-to-end case lifecycle management from intake to closure
  • Integrated time tracking and invoicing in Philippine Peso (₱)
  • Secure document upload, preview, and download per case
  • Shared calendar for hearings, meetings, and deadlines
  • Real-time in-app notifications and comprehensive activity audit logs
  • Server-side pagination across all data listings for performance at scale
  • Modern, professional UI designed for legal professionals

4. Core Features & Modules

📊 Dashboard

Executive overview with KPIs (active clients, cases, hearings, outstanding invoices, tasks due today), charts for case status distribution, revenue trends, and task priorities. Recent activity feed included.

👥 Client Management

Full client directory supporting individual and corporate clients. Search, filter, create, edit, and profile views with linked cases. Archive support for inactive clients.

⚖️ Case Management

Case creation with categories (Civil, Criminal, Corporate, Family, Real Estate, IP, Labor, Tax, etc.), status tracking, lawyer assignments, court details, notes, timeline, and linked documents/tasks.

📁 Document Management

Upload, categorize, preview, and download case documents. Categories include pleadings, evidence, correspondence, contracts, court orders, and research materials.

✅ Task Management

Task creation with priorities (Low to Critical), due dates, assignees, and case linkage. List view with pagination and Kanban board view for visual workflow management.

📅 Calendar & Events

Schedule hearings, meetings, court appearances, deadlines, and reminders. Day, week, and month views with case association and date-range filtering.

💰 Billing & Invoicing

Time entry logging per case and lawyer, automated amount calculation, invoice generation in ₱ (PHP), status workflow (Draft → Sent → Paid → Overdue), and payment recording.

🔔 Notifications

In-app notification bell with unread indicators, mark-as-read, and read-all functionality. Keeps staff informed of case updates and system events.

📋 Activity Logs

Full audit trail of system actions — who did what, on which entity, with timestamps. Essential for compliance and internal accountability.

🔐 Authentication

Secure login, forgot password, and reset password flows. Session management with NextAuth. Demo admin account available for evaluation.

Data Listing & Pagination

All major listing pages include server-side pagination with configurable page sizes (10, 20, 50, 100 records), ensuring fast performance even as data volumes grow.

5. User Roles & Access Control

The system implements granular Role-Based Access Control (RBAC) with seven predefined roles:

Role Description Key Permissions
Super Admin System administrator Full access to all modules and settings
Managing Partner Firm leadership All operational modules; user read access; activity logs
Lawyer Attorney / counsel Clients, cases, documents, tasks, calendar, billing (create/read)
Paralegal Legal support staff Cases (read/update), documents, tasks, calendar
Secretary Administrative staff Clients, cases (read), calendar, tasks (create/read)
Accountant Finance / billing Billing full access; clients and cases (read only)
Client External client portal Limited read access to own cases, documents, and invoices

6. Security & Compliance

  • Password Security — Bcrypt hashing for all stored credentials; password complexity enforced on reset.
  • Session Management — Secure server-side sessions via NextAuth v5 with middleware-enforced route protection.
  • Permission Middleware — Every server action validates user permissions before data access or mutation.
  • Activity Auditing — All significant actions logged with user, entity, action type, and timestamp.
  • Input Validation — Zod schema validation on all forms and API inputs to prevent injection and data corruption.
  • Document Access Control — Documents served through authenticated API routes with permission checks.
  • Data Isolation — Role-based data visibility ensures staff only access information appropriate to their function.
